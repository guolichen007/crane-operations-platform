# 报备中心四角色人工 UAT 脚本（G4-S1A 修订）

**状态：脚本已准备，真人 UAT 未执行。** 本脚本须在隔离 Preview 上用 Preview realm 的企业 OIDC 合成账号执行（`DEV_AUTH=0`，不得用开发登录代替）。目前 Preview 尚未部署，判定栏全部留空。下文“已有自动化预演”一列只说明：同样的步骤已在本地合成栈上由 `tests/baobei/uat/uat.spec.ts` 自动走通，这不等于真人验收，**不得用自动化结果代签判定栏**。

**数据准备。** Preview 部署后，先用 `tests/baobei/preview/seed.mjs`（OIDC 模式、标记“合成UAT”）准备背景数据：四角色、12 个阶段、已知/未知/零金额、一条退回、一条已批准、一条跨组重复（待总监裁决）、一条待分配草稿。本脚本中的操作再另外新建以 `UAT-<日期>-<执行人缩写>` 开头的项目，避免与背景数据混淆。
