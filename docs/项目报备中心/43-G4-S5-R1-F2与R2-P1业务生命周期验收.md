## R2-P1-F1 撤销账号安全补丁（基线 13f729a，CI Run 43199125196 Attempt 1 8/8）

`removeLogin()` 重写为只返回“已确认”或待核对原因，首次请求与恢复/核对共用 `completeRevoke()`，每次都重新读取 Keycloak：

| 情形 | 处理 | 手机号 |
| --- | --- | --- |
| 记录的用户不属于本成员 | 不删除、不停用、不改名、不改角色；REVIEW `OWNER_MISMATCH`；映射不变 | 不释放 |
| 删除失败 / 结果未知仍存在 | 仅本人用户保持停用；REVIEW `REVOKE_DELETE_FAILED`；核对时重试删除 | 不释放 |
| 删除超时但已删除 | 再读确认不存在 → 继续 | 登录名空闲后释放 |
| 用户已删除但登录名仍被其他账号占用 | REVIEW `LOGIN_STILL_OCCUPIED` | 不释放 |
| 任何读取失败 | REVIEW `PROVIDER_UNAVAILABLE` | 不释放 |
| 删除成功且登录名空闲 | 单事务 REVOKED + 审计 | 释放 |

反证 `TestDatabaseR2P1F1RevokeSafety`（8 组，PG 18.4）：在 13f729a 上 1、3、8 失败（旧代码对他人用户执行停用并标记已撤销、删除失败仍释放手机号、查询失败仍完成），新代码全部通过。真实 Keycloak 删除失败恢复：NOT_RUN（本 VM 无 Keycloak 环境）。
