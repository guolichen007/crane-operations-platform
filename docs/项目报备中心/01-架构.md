# 架构与信任边界

Vue 3.5 + TypeScript + Vite + Pinia + Router + lucide，局部 Reka Dialog。独立 npm lock，不修改 Crane workspace。
Go API 独立 module；pgx PostgreSQL，独立迁移版本表；compose project u-dao-baobei，服务 baobei-web/api/postgres，无 container_name。
浏览器同源 /auth 和 /api 由 web 代理给 BFF。JWT/refresh token 不给浏览器。OIDC discovery/JWKS 验证 issuer/audience/expiry/nonce，授权码 + PKCE + state，短期一次性 state 存服务端；生产 HTTPS 且独立 __Host-baobei_session，Secure/HttpOnly/Lax/Path=/，八小时不滑动 session。
Session 只保留 subject/name/有效角色/team；随机会话摘要存数据库。Mutation 同源 Origin + session CSRF header，JSON 严格解码、限制 body 大小、禁止客户端指定 owner。
开发认证只有 APP_ENV=development + DEV_AUTH=1 + loopback listen，固定 synthetic 身份；Compose 开发显式标识，生产不接受该模式。
角色 sales 仅 owner，manager 有效 team，director 全局，admin 治理不默认读取销售详情。team 从数据库有效 app_users 取，不信任浏览器/team 声明。

## 一致性
行级 SELECT FOR UPDATE + version 比较。所有写入项目快照与结构化关系、审计处于同一事务。编号由 PostgreSQL 年份计数行生成 BB-YYYY-NNNNNN。
提交短事务先获取全局 advisory transaction lock（覆盖近似/alias fingerprint 不一致），再获取 fingerprint lock；重读状态，重新查重。后提交的高风险项目 UNDER_REVIEW，绝不静默获得第二有效归属。全局锁是 B1 保守策略，吞吐优化留后续审查。
查重用 NFKC/空白/标点/大小写归一，保留公司后缀；pg_trgm 项目相似度、组织 alias。阈值来自 reference_values；提交强制重查。sales 只收匿名风险信息，无其他项目 UUID、名称、备注、联系人或报价。

## 安全与失败
统一 code/message/requestId/details；禁止原始 SQL 错误外泄。应用不记录请求 body/query/token/cookie。Nginx access_log off，尤其 callback。权限在服务端所有对象读取与修改强制执行。
超时/重复点击由 ActionButton 阻止；提交/跟进同状态或过期 version 冲突拒绝，OCC 防重复跟进。草稿 create 由客户端一次请求串行保存，失败保留表单。
未来 adapter 仅 interface，生产 endpoint 不声称可导入 Crane。一次性 auth state 有界有效期；滚动部署需固定单 BFF 实例，后续可改数据库 state；session 跨重启有效。
