# 数据模型

> 本文为早期模型记录，审批、转移和保护期已在后续批次实现。完整当前约束与未来nullable owner/提交快照见[数据库ADR](16-待分配草稿与数据库迁移ADR.md)。全角色G0不执行迁移，不修改旧SQL。

独立数据库；migrations/00001_init.sql 起，版本按文件 sha256 校验，forward-only，不改 Crane migration。
核心 intake_projects 独立列保存 id/registration_no/project_name/normalized_project_name/owner_subject/created_by_subject/team_id/intake_status/sales_stage/protection_status/information_source/confidence_level/project_type/estimated_amount/expected_purchase_date/last_activity_at/next_followup_at/version/created_at/updated_at。document 为可演进快照，位置、关系方、计划设备和需求同步结构化表。
organizations/aliases 存终端身份，project_parties 区分 END_CUSTOMER/EPC/DESIGN_INSTITUTE/CRANE_MANUFACTURER/SYSTEM_INTEGRATOR/AGENT/OTHER。contacts/project_contacts 预留；B1 不采集私人联系方式。
project_locations 包含 province/city/district/industrial_park/factory_name/workshop/address_detail，坐标可选且 B1 不采集。
planned_equipment 字段 equipmentType/quantity/manufacturer/model/capacityTons/spanM/liftHeightM/controlMode/plcBrand/plcModel/driveBrand/notes/confidenceLevel，绝不属于正式 Equipment。
project_requirements 多选 AUTONOMOUS/ANTI_SWAY/COLLISION_AVOIDANCE/POSITIONING/VISION/LIDAR/REMOTE_OPERATION/SAFETY/MONITORING/OTHER。
app_users/teams 管有效身份与团队。project_activities 存跟进时间、摘要、结果、下一步及下次时间。
duplicate_cases 留提交风险摘要，approvals/ownership_history 预留后续批次；conversion_jobs/links 预留迁移任务与幂等键；audit_events 只记录事件元数据不存请求全文；reference_values 配置阈值和字典。

状态拆分：intake_status（DRAFT/SUBMITTED/UNDER_REVIEW/APPROVED/RETURNED/REJECTED/EXPIRED/CANCELLED/CONVERTED），sales_stage（L0_LEAD…L8_PENDING_CONTRACT/WON/LOST/HOLD），protection_status（ACTIVE/WARNING/EXPIRING/EXPIRED）。B1 草稿/退回可编辑提交，提交后跟进允许，审批与保护期调度尚未启用。
归属初始由 session 填入；归属转移接口本批仅契约。新建/修改/提交/跟进分别递增 version；客户端必须提交最新 version。
