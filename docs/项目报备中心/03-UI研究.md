参考官方公开资料（仅学习交互，未复制 Twenty AGPL 源码/品牌/素材）：
- Twenty layout: https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/getting-started/core-concepts/layout.mdx ：紧凑表格 + record side panel + full record link + timeline。
- https://shadcn-vue.com/docs ：表单按任务分组，Sheet/Dialog 与统一动作状态；不使用其生成器、不引入 Tailwind。
- https://reka-ui.com/docs/components/dialog ：modal focus trap、Esc、标题描述与焦点返回。
- https://tanstack.com/table/v8/docs/guide/sorting ：筛选、排序与分页应保持一致状态；B1 采用小型原生表格，不新增 Table 运行依赖。

视觉决策：216px 灰白侧栏、56px 顶栏，品牌蓝用于主动作，轻量数字条，44–48px 表格行，右侧 Sheet，详情时间线。移动 390px 切卡片而非横滚，表单单列、固定底部操作栏。

新增直接依赖范围仅独立产品：Vue/Pinia/Router/Vite/lucide（MIT），Reka UI（MIT），pgx（MIT）、go-oidc（Apache-2.0）、oauth2/text（BSD-3-Clause）。开发工具 ESLint/TypeScript/Vitest/Playwright/Swagger Parser/Ajv/YAML；锁文件精确解析。无 React/大型 UI/三维依赖，无根许可证选择。
