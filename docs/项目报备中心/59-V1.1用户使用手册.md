# 59 · Baobei V1.1 用户使用手册

网址：https://baobei.youdaozd.com 。用手机或电脑浏览器打开即可。登录账号就是你的 11 位手机号（第一次登录用管理员给的临时登录名）。

## 一、所有人

**第一次登录（首次认领）**

1. 用管理员给你的**临时登录名**（例如 `sales01`）和**临时密码**登录。
2. 按提示设置你自己的新密码。
3. 在“完成首次登录”页面填写**真实姓名**和**本人手机号**，然后点“确认并改用手机号登录”。
4. 看到“认领完成”后，点“用手机号重新登录”，再用**手机号 + 新密码**登录。临时登录名从此作废。

> 手机号格式不对、或已经被其他成员使用，页面会直接提示，按提示改正即可。认领完成前，系统的其他页面都打不开，这是正常的。

**日常**

- 右上角头像可以看个人资料、修改密码、退出登录。
- 忘记密码请联系管理员“重置密码”，用新的临时密码登录后再改成自己的密码。
- 账号被停用时无法登录，请联系管理员。

## 二、销售

- **新建报备**：点左上角“新建报备”，按三步填写客户、项目和需求，可以先保存草稿，确认无误后提交审核。
- **重复提示**：系统发现可能重复的项目会提醒你，请如实说明。
- **项目中心**：查看自己负责的项目，按阶段推进（L0 线索 → 赢单/输单/搁置）。
- **跟进中心**：逾期、今日、本周的跟进一目了然，登记跟进时写明结果和下次计划。
- **客户中心**：维护本团队的客户档案和联系人。
- **技术需求**：在项目详情里填写技术简报，回答技术问题。
- **数据分析**：查看本人的统计。

## 三、主管

在销售功能之外，主管还可以：

- **审核中心**：审核本团队销售的报备，可以通过、退回（写明原因）或驳回。审核记录不可修改。
- **团队成员**：查看本团队成员，新增本团队销售；需要开通账号时请联系管理员。
- **数据分析**：查看团队和成员的统计。

## 四、总监

- **审核中心**：审核主管本人提交的报备。
- **数据分析**：查看全部团队，可以按团队和成员下钻。
- 查看全部项目和客户（只读为主），不参与报备。

## 五、管理员

**人员管理**（左侧“人员管理”）

| 操作 | 怎么做 |
|---|---|
| 新增成员 | 点“添加成员”，填写姓名、角色和团队。知道手机号就填工作手机；还不知道的，勾选“发放临时登录名”，填一个临时登录名（如 sales06），由本人首次登录时填写手机号 |
| 开通账号 | 在成员详情点“开通登录账号”。页面**只显示一次**登录名和临时密码，请当面或私信交给本人 |
| 重置密码 | “重置密码”会生成新的临时密码，并让成员当前的所有登录失效 |
| 更换手机号 | “更换登录手机号”：旧号立即不能登录，成员需要用新号重新登录（认领前的成员不能代填手机号） |
| 停用 / 恢复 | 停用后立即无法登录；未结束的项目会进入交接队列，可以移交给其他销售 |
| 改角色 / 调组 | 编辑资料并写明原因；改角色后要点“同步登录角色”，成员本人重新登录后生效 |
| 账号异常 | 状态显示“处理中”或“待核对”时，点“核对账号状态”，系统会读取真实登录状态后完成、撤销或保持待核对，不会重复执行 |

**团队管理**：新建、改名、归档或恢复团队。已归档的团队保留历史，但不能再加入新成员。

**注意**

- 涉及管理员、总监、主管的账号操作，系统会要求你**再次输入自己的密码**确认。
- 所有人员和账号操作都有审计记录，不能删除。
- 不要把临时密码写在群聊或公共文档里。
