# 交互动作矩阵（UI 交互 SSOT）

所有业务按钮统一 ActionButton，具有 Default/Hover/Focus-visible/Pressed/Disabled/Loading；所有 button 明确 type。异步立即锁定、finally 恢复；成功更新状态与 Toast，失败保留输入并显示可读错误。禁用必须 title 或附近说明。

搜索/筛选/select/checkbox 为表单控件；实时查重 debounce 450ms，自动保存 debounce 1200ms，使用 aria-live 提示。表格行支持 Enter/Space，Modal 捕获焦点、Esc、显式返回焦点。离开表单/有内容的跟进 Dialog 有 Unsaved Changes Guard。
