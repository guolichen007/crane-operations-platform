## 2. 彩排环境要求（服务器 CC）

- **独立 VM 或独立 Docker Engine。** 禁止在现网 Docker Engine 上运行 `direct-deploy.py up/migrate/rollback/switch`，因为 Compose 项目名固定为 `u-dao-baobei`。
- **隔离组件：**
  - PostgreSQL 18.4，镜像 digest 与生产 compose 一致，Schema 00005。
  - 生产备份的**脱敏**恢复副本：手机号、姓名、邮箱替换为合成值，并记录脱敏脚本的 sha256。绝不回写现网。
  - Keycloak 26.8.1，两个 Realm `crane`（替身）和 `baobei`。客户端、mapper、scope 按《Keycloak生产配置契约》配置，另有测试管理员。
  - 由候选 SHA 构建的 Web/API 镜像，以及现网版本 7b95580 的镜像。
  - 真实 Docker Compose、Nginx、Chromium。
- **配置：**
  - `APP_ENV=production`、`DEV_AUTH=0`，不使用任何 mock。
  - 彩排用的 Issuer 为隔离 Keycloak 的地址。`REALMS` 和 `deployedProfiles` 中的 Issuer 需要通过**彩排专用分支上的一行补丁**指向隔离 Keycloak，并在报告中列出该补丁的 diff 和 sha256；不得修改正式分支。
