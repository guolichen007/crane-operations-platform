## 5. 独立复核（B 阶段）结论与处理

由独立审查代理只读复核 B 阶段 API diff：无 P0。已整改：

1. 他组以同名新建客户时返回主档原拼写（暴露“某组已有完全同名客户”）→ 团队资料保存本团队拼写，显示优先本团队拼写。
2. 已停用联系人无法取消关联 → 取消关联只需关联存在。
3. 无变化的关联/取消关联写入审计 → 未变化返回 409，不写审计。
4. 运行时对 contacts/团队资料/技术表有整表 UPDATE → 改为列级授权。
5. 已停用联系人仍可编辑 → 409 INVALID_STATE。
6. 并发首次编辑团队资料 503 → ON CONFLICT 返回 409。
7. 跟进列表与计数不同快照 → 同一 REPEATABLE READ 只读事务。
8. 技术问题关闭在锁定后未复核读取权限 → 锁定后复核。
9. 已废弃/已转换项目仍可关联联系人 → 409。
10. 审计细节 → 联系人修改记录前后值（电话脱敏），客户资料记录备注。

记录未改：搜索 `q` 中的 LIKE 通配符未转义（只影响本人可见范围内的匹配，P2）。
