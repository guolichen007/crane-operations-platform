# 初始威胁模型

恶意设备越权：独立证书身份、固定 namespace ACL、topic/payload 身份一致性校验；测试跨设备写入和设备写命令被拒绝。生产补充证书撤销、租户隔离与身份生命周期。
重放乱序：持久 bootSeq/sequence 去旧、事件 message_id 幂等；不依赖设备 UTC 判断新旧。WATCH 的 leaseId/generation 围栏与持久命令去重隔离历史 STOP；broker 剩余 Message Expiry 转为 Edge 单调时钟截止时间，设备时钟异常不能使本地积压命令无限有效。真实时间同步仍需后续设备适配验证。
凭据窃取/CSRF：HttpOnly SameSite cookie、同源 WS 检查、写请求 Origin 检查、最小开发暴露范围；生产使用 HTTPS 和短期真实用户会话。开发 bearer 为单管理员，非生产能力。
资源耗尽：消息 32KB、事件 spool 256、broker 队列有界、WS 写超时、连接池上限、LIVE TTL。补充攻击速率限制、设备隔离和容量压测列入后续验收。
云/网络故障：本地系统自治、指数退避、关键事件应用 ACK、遥测丢旧、Edge TTL。Cloud 从持久 Viewer/Desired State 恢复并重新对账；Will Delay 减少短断抖动。spool/启动计数损坏时拒绝静默重置。数据库恢复到旧代次、磁盘丢失、多写者与生产审计完整性仍需后续验收。
