# 安全边界

云端不可成为设备安全运行前提，Edge 只向外连接 MQTT，不开放管理入站。当前无 PLC/控制板代码、无真实控制命令契约。
开发 Mosquitto mTLS + 证书 CN ACL，每设备独立证书；Cloud 专用身份。主机仅 loopback 发布 Web/API/MQTT，PG、Gateway 不发布。开发容器为读取 0600 bind keys 有 root override，严禁将此 Compose 当作生产部署。
Cloud 默认拒绝未知/弱凭据，开发随机 bearer/cookie 适配器只允许 APP_ENV=development，production 启动失败。生产必须独立身份提供方、TLS、租户/设备授权、吊销、限流与审计验证。
远程/点云入口关闭，浏览器不持有 MQTT 凭据。公共 fixtures 匿名，生产配置另存私有环境。根许可未确定，不能擅自授权商用代码开源。

T0.5 的 event/ack 仅允许 Cloud 发布、设备读取自身 Topic；不会新增控制能力。TEST-001 证书仅用于隔离故障测试，不计入 20 台业务模拟器；bootstrap 在本地开发 CA 下签发，私钥不入库。Edge 指标只监听容器 loopback:8083，无宿主端口映射或管理接口。
