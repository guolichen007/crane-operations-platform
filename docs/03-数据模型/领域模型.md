# 领域模型

Tenant → Project → Device，设备用全局匿名 ID。Shadow = 最后已持久化消息 + 接收时间 updatedAt + 云版本。设备位置/负载属于观测，不是控制目标。
Message 以 bootId/sequence/messageId 区分重启、顺序和重复。MQTT 连接、Edge 与 Controller 健康独立；过期数据必须显示最后更新时间。
LiveSession = 用户/设备/到期时间/采样频率，聚合 upstream；RemoteSession 后续增加 idle timeout、来源和 audit id。用户角色 viewer、operator、maintainer、platform_admin，未知角色拒绝。
Phase 0 开发身份是一个本地管理员，RBAC 策略有单测；未提供生产身份目录或多租户授权实现。
