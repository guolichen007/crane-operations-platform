# PostgreSQL 与迁移

使用 pgx database/sql + Goose。deploy/postgres/migrations 顺序 SQL，开发启动显式 --migrate；不用 ORM 自动改表。CI 从全新 Compose volume 重建。
基线包含 tenants/projects/devices/device_shadow/device_heartbeats/telemetry_samples/alarms/events/live_sessions/remote_sessions/audit_logs/users/roles/user_roles。device_shadow 主键设备；事件/告警主键 message_id；采样按 device_id/time 索引。
每条 Shadow 先事务提交再更新 cache。LIVE 最多每 10 秒写 telemetry_samples，避免每浏览器一份写入。Shadow 活跃状态仍逐条持久化，这是 Phase 0 简单实现，生产需按性能证据评估写入策略与保留期。
降级迁移 Down 只供空开发环境回滚，会删除业务表。生产采用 forward-fix，先快照和验证备份；禁止修改已应用编号。无点云字段、无原始点云入库。
live/remote 会话表为后续持久化预留，当前 POC 使用内存租约。
