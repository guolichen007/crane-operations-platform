# 设备详情数据语义

Last Known State 是已落库最后观测，展示 updatedAt、消息 kind、连接与三类健康。静默时位置可能一小时未更新，不能称作实时。
LIVE 仅在用户申请租约后订阅；页面显示租约到期和最近消息类型，断流保留最后状态并提示连接中断。停止查看、离开页面关闭会话；浏览器意外退出由 TTL 兜底。
Point Cloud 与 Remote Local Web 明确 Phase 2 未启用，不能展示伪造通道。Alarm 为独立消息通道，沙盘原告警演示与 Cloud API 告警需标识数据来源。
生产还需 stale 阈值、离线判定细化和来源权限设计；当前 Mock 不反映真实机械工况。
