# S3.5 云端数据与会话语义

本轮沿用现有 Vue、Pinia、原生 fetch/WebSocket 和生成的 TypeScript Contract。只调整前端及验证脚本，不修改 Cloud、Edge、MQTT、PostgreSQL、300 秒默认 Viewer TTL 与 Grace。

## 数据来源

| 区域 | API 模式 | Demo / 离线模式 |
|---|---|---|
| 首页 Cloud Runtime | `/api/v1/devices` 与 `/api/v1/alarms`，每15秒刷新 | 不展示 Cloud Runtime |
| 告警中心 | Cloud Alarm，查询最近最多100条上报记录 | 固定 DEMO MOCK，本浏览器确认 |
| 设备台账与详情 | PostgreSQL Shadow；主动申请 Viewer 后订阅实时流 | 原沙盘演示设备台账 |
| 全国地图 | 匿名登记 / DEMO 空间资产 | 相同空间资产 |
| monitor / analytics / maintenance / remote | 仍明确标为 DEMO | DEMO |

Cloud Runtime 接入数量来自设备数组长度，MQTT在线来自 `presence.connectivity=MQTT_CONNECTED`，实时查看来自 `upstreamStatus=LIVE` 的设备数，不是 Viewer 人数。告警数量是本次 API 返回的历史记录条数，不等同于未处理或活动告警数。Contract 仅有 ALARM 的 code、text 与 Envelope 身份/时间；无严重度、处理状态、云端确认接口，API 页面不显示 Demo 确认按钮。

API 失败时展示错误；有上次结果时明确标注保留结果，不混入 Demo 回退。所有 Cloud 时间通过 `Intl.DateTimeFormat` 使用 Asia/Shanghai，显示年月日与秒；原 ISO 保留在 time 的 title/datetime。无值、非法值与 Go 零时间显示“—”。

SIM 是模拟设备，没有可信省市或经纬度。Cloud 查询模块与地图数据源分离，本轮不建立任何位置映射或假字段。未来 Phase 1-B 可设计独立 project/site metadata，再经明确的地理数据入口连接空间资产；不把设备局部 XYZ 当作经纬度。

## 状态与 LIVE

“在线 · 静默监测”对应 MQTT_CONNECTED / SILENT：设备仍保持连接，仅上报心跳和状态快照；用户申请 LIVE 才开启实时数据流。详情保留协议技术值以便诊断。

前端 ViewerState 仅描述浏览器传输，不改 Cloud 上游状态：CONNECTING、LIVE、RECONNECTING、POLLING_FALLBACK、STOPPED。连接中断提示“实时流中断 · 正在重连”；15秒 Shadow 轮询成功后提示“最近状态可用 · 实时流正在恢复”。连接恢复清除连接错误，复用仍有效的 Viewer，不再次 POST 申请租约。上游 STARTING → LIVE 继续以设备应用回执后的 Shadow 为准，WebSocket 打开不代表设备已确认 LIVE。

原生 WebSocket 按1、2、5、10秒退避，后续间隔上限10秒；仅在页面有 LIVE 意图且 Viewer 未到期时重试。主动停止、导航、卸载与租约失效均撤销重连和续租。异步 open/renew 的代次校验防止停止后恢复状态；晚到的 open 结果尽力 DELETE。

## 刷新与离开

成功 open 后保存 sessionId 到当前 Tab 的 sessionStorage，键为 `crane.cloud.viewer`。主动停止清除此键并 DELETE；pagehide / beforeunload 使用 keepalive DELETE，不阻塞卸载，不重复清理。卸载清理失败保留旧键，重载时先尝试清理旧 Viewer，再显示 Last Known State。重载不会自动申请或恢复 LIVE，旧租约清理失败时也不会创建新 Viewer。

sessionStorage 被浏览器禁用、请求响应丢失、断网、崩溃、断电时，无法保证关闭通知送达。默认300秒 Viewer TTL + 服务端 Grace 继续作为最终兜底；没有修改后端截止时间或协议。浏览器续租也受云端 expiresAt 限制。

设备列表通过 flex 容器内滚动、底部 padding 和 scroll-padding 留出固定 CloudStatus 安全区；不重做业务页布局。1920×1080 的 SIM-019 / SIM-020 完整卡片边界由浏览器自动断言验证。
