## 2. 源码直部署（LOCAL_DEV_DEPLOY）

服务器只用已提交源码构建。要求完整 SHA 且工作树干净。镜像名为 `crane-local/<svc>:<SHA>`，不推送，构建时 `--pull=false`。同一 SHA 的内容如果不同，拒绝覆盖。启动时 `--pull never`，部署后核对运行容器的 image ID 和 revision。只重建输入有变化的服务。迁移时必须提供备份。current、previous 和回退记录写在 `/srv/u-dao/releases/crane-local`。本地镜像只允许在 crane-dev 使用，正式发布工具没有改动。契约测试 3 项。手册：`docs/08-部署运维与成本/R8-crane-dev源码直部署与模拟行车接入手册.md`。

## 4. 资源与排期（新增）

| 能力 | 后端 | 前端（项目组合页） |
|---|---|---|
| 资源创建/查询 | 校验类型、容量、独占=1、时区，不合法返回 422；跨组合 403 | 「资源」页：新建、列表（容量、独占、可否覆盖） |
| 资源日历 | GET/PUT 带版本，过期返回 409；规则不合法 422；只有经理能写 | 经理编辑每周规则，规划员只读 |
| 排期创建 | 时段必须 start<end 且不超过 366 天 | 「排期」页：新建 |
| 资源预约 | 排期须为 PLANNED，预约时段在排期内，资源同组合，数量不超过容量；撤回需 If-Match | 每个排期都有预约面板，可新增、撤回 |
| 审批 | 在资源锁内重新检测冲突；有阻断冲突返回 409 `schedule_conflict` 并附明细，冲突单独落库；批准后生成不可变基线 | 只有经理能看到「批准」；出现冲突时提示原因并引导去冲突页 |

| 历史 | 每次批准生成一个基线版本（快照 + sha256），之后的取消不改写历史 | 「排期历史」页 |
| 修改/撤销 | 排期取消：PLANNED 或 APPROVED → CANCELLED，需 If-Match 和原因，已批准的只有经理能取消；预约会被释放 | 「取消」按钮 |
