# 前端架构

Vue 3 + TS + Vite + Pinia + Router + Three.js + ECharts。原 src/public/scripts 迁到 apps/web-console；npm workspaces 单 lockfile。根 tests/e2e 为浏览器回归，组件单元测试位于 app/tests。
默认离线演示模式，保留全国省份数量标签和已有防频闪行为。公开 fixtures 已匿名；原客户版保存在本地归档，不能上传。
VITE_DATA_MODE=api 时 /devices 与 /devices/:id 使用 Cloud API，底部开发登录仅本地验证，凭据输入后清空且不保存 localStorage。地图仍为匿名可视化样例，明确标识；不把模拟地图当作实际接入分布。
routes 含 overview/projects/devices/detail/alarms/remote/system。Phase 0 首批完成 Overview、Devices、Detail；其余既有演示功能和后续业务要区分。
npm run build:html 输出 release 单 HTML，内嵌脚本、样式和压缩地图，浏览器 file:// 可打开。离线包为沙盘演示，不包含开发凭据或云连接。地图合规说明见本目录对应文档。
