## 交付行为

- 薄 Cloud client 统一 devices/shadow/alarms 与 Viewer open/renew/close；继续使用生成类型，无新增依赖或第二套契约。
- API 告警页只读取 Cloud Alarm，展示 deviceId、code、text、sentAt 与来源。接口无 ACK/处理状态，页面不制造该能力。Demo/离线页独立保留固定 Mock 告警与本机确认。
- 首页独立 CLOUD RUNTIME：Cloud接入数量、MQTT在线、上游LIVE设备数、最近最多100条告警记录数。接口失败明确报错，不混用 Demo 补数。SIM 标为模拟设备；没有可信地理元数据，不向地图注入点或假经纬度。
- 所有可见 Cloud 时间统一为 Asia/Shanghai，原 ISO 在 title/datetime 保留；SILENT 显示“在线 · 静默监测”及节流解释。
- 原生 WS 按1/2/5/10秒退避恢复，停止/离页/租约到期后不重连。UI 区分连接、实时流、重连、Shadow轮询回退与停止；Cloud STARTING → LIVE 仍依赖设备应用回执。
- 当前 Tab 的 sessionStorage 保存 Viewer；pagehide/beforeunload 尽力 keepalive DELETE，刷新先清旧租约再回 Last Known State。异步 open/renew 与卸载竞态有反证，浏览器崩溃仍依赖服务端 TTL。
- 最小 CSS 安全区修复固定 CloudStatus 遮挡；离线 HTML 构建固定使用 Demo 模式。
