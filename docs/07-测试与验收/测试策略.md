# 测试策略

契约：生成漂移检查、JSON Schema 正反例、REST/AsyncAPI 结构；禁止真实控制消息。Go：状态机、租约引用、RBAC、乱序/boot、spool 恢复容量、点云二进制边界。
Web：原有 23 单元测试及沙盘 26 E2E，防频闪和省份数量行为回归。Cloud Web 验证实际登录、20 Shadow 台账、设备最近状态。
集成：空 PostgreSQL Goose migration、1 台先打通再 20 台、mTLS ACL、WATCH/LIVE/renew/stop/expiry、告警幂等、乱序、LWT 与恢复。tests/integration/run.mjs 只用匿名数据，记录实际证据到本地忽略目录。
CI 六 job：repository-contract/backend/edge/frontend/integration/security。全通过且创建 Draft PR 才可标 Phase0 完成。工具缺失/网络失败应记 BLOCKED，不冒充通过。
性能目标留给后续阶段，当前不能从功能测试推导 30 分钟点云稳定或 20 用户容量结论。

GitHub 无 GPU runner 使用 deviceScaleFactor=0.25 降低像素填充成本，CSS 视口、相机几何、标签、拾取和90帧稳定性断言保持一致。本机完整分辨率26项回归验证视觉行为；CI 软件渲染不作设备帧率/容量验收。
