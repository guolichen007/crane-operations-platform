## 交付内容

- 公共 Envelope + 10 种具体 Payload 类型，覆盖 13 个 kind、10 个 Topic；Go/TypeScript/严格 JSON Schema/AsyncAPI 单源生成，OpenAPI 标准解析与漂移检查。
- bootSeq 持久递增，bootId 随启动变化；设备 UTC 不决定消息新旧；每连接序列区间隔离延迟 Will。Presence/业务快照分离，离线保留 AUTO、XYZ、负载。
- Adapter 返回内部领域数据，Mapper 填入协议身份；只有 Mock，无真实驱动。
- PostgreSQL 持久 Viewer Lease、设备 upstream desired 与 WATCH 命令结果；一个设备多个 Viewer 共享一条 upstream；generation fencing、持久命令去重、WATCH_ACK 确认与重启对账。
- ALARM/EVENT 仅在 Cloud 提交后返回 STORED，Edge 收到应用 ACK 才持久删除；原 messageId 重试与数据库幂等；256 条有界 spool、Linux 文件与目录 fsync。
- MQTT5 Will Delay、WATCH Message Expiry、单调时钟本地截止时间、SIGTERM/SIGINT graceful DEATH；Cloud/Edge 指标与结构化日志。
- 00002 有序迁移、三条 ADR、架构/协议/安全/运维说明；保留 Phase0 报告与证据。
