# Phase1-A1.1-R2 文档索引

本目录是 R2 成熟化实施的单一文档入口。不同文档职责不重叠：

- `00-项目总览`：产品定位、能力路线、范围。
- `01-系统架构`：模块化单体的领域边界和依赖规则。
- `03-数据模型`：数字资产、项目排期、可靠性、历史时态数据模型。
- `04-身份与权限`：Portfolio Scope 与 Project Scope 双域授权。
- `04-前端与可视化`：工业工作台、Three、GLB、性能和交互。
- `06-安全与合规`：敏感度、合规载体、审计与文件安全。
- `07-测试与验收`：所有 Batch 的自动化验证和业务验收。
- `08-部署运维与成本`：Local/CI/Server 分工、迁移和发布。
- `09-ADR`：为什么选这些技术、为什么不选其它技术。
- `产品设计`：用户工作流、页面能力、项目/资产/运维产品规格。
- `架构`：API 规范、REA 模式来源、性能预算。
- `项目管理`：分批计划、状态交接、服务器演练、Batch 卡。
- `templates`：REA evidence、Handover、数据字典模板。
- `参考资料`：外部官方来源、许可证和使用边界。

**维护规则**：方案变化先更新对应的“权威文档”，再更新总蓝图和当前状态，禁止同一规则在 5 个文件分别维护导致漂移。
