# 组件职责

apps/web-console：地图、台账与数据语义；从 Cloud 获取状态，不持有设备凭据。
services/cloud-api：REST/WS、缓存、数据库与会话；services/remote-gateway：Phase 2 的受控入口，当前 fail-closed。
edge/agent：出站 MQTT、状态机、适配器、有限事件补传；simulators/device-simulator：启动多个相同 Edge 核心的匿名 Mock 实例，不复制协议 DTO。
edge/pointcloud-bridge：仅适配边界骨架；contracts/pointcloud：帧校验和 latest-frame-only 原语。无 ROS 真实采集与云上传。
deploy：开发部署和有序迁移；tests：跨组件契约、集成与浏览器；tools：证书、代码生成和诊断。生产适配需资产盘点决定，不写死厂商。
