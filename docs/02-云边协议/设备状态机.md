# SILENT / LIVE / EVENT

正式模型见 edge/agent/internal/domain。初始 DISCONNECTED，连接后 SILENT；WATCH_START/RENEW 建立有限租约进入 LIVE，TTL 到期或 STOP 返回 SILENT。
EVENT 是临时优先态；完成发布后恢复原来的 LIVE（若租约仍有效）或 SILENT。断线不改变本地控制系统，不无限保存遥测。
默认 KeepAlive 300 秒、业务心跳 900 秒、snapshot 3600 秒、LIVE 1 Hz。开发 Mock 仅模拟位置和负载，不驱动设备。统计小时/日汇总未实现。
租约到期/停止后发送状态快照，让最近状态明确显示 SILENT。状态机测试覆盖事件返回、过期和断开。T0.5 增加持久 generation、命令应用 ACK、Cloud Desired State 对账和网络故障反证；真实设备运行状态和生产命令授权仍待后续验收。
