# 实时会话协议

POST /api/v1/devices/{id}/live-sessions 申请，POST /live-sessions/{sessionId}/renew 续租，DELETE 关闭。默认 TTL 300 秒，grace 45 秒，采样固定 1 Hz，不接受客户端任意高频采样请求。
live_sessions 持久化每个 Viewer Lease；device_live_state 持久化一个设备的 upstream leaseId、generation、desired_until 和状态。首位 Viewer 建立 START，其他 Viewer 延长共享 desired_until，不重复建立 upstream；最后引用释放或过期后 grace 再 STOP。Edge 独立按 TTL 退出，Cloud 故障不会永久 LIVE。
WebSocket /api/v1/devices/{id}/stream 使用同源 HttpOnly 开发会话，读取同一缓存；每连接写入有超时，不累积无限帧队列。
201 只表示 Viewer Lease 已建立。upstreamStatus=STARTING，收到匹配当前 commandId/leaseId/generation 和设备 boot 的 WATCH_ACK 后才为 LIVE；PUBACK 不能替代应用回执。device_commands 保存 PENDING/APPLIED/FAILED/EXPIRED，超时可见并重新对账。

START 只接受更高 generation，RENEW/STOP 只接受当前 generation 和 leaseId；同 commandId 持久去重。BIRTH、Cloud 重连时从 PostgreSQL 重算 desired，发起新 generation 的 START，隔离旧连接积压命令。Edge 重启保留 fencing，但不恢复旧 LIVE 定时器。

开发验收可配置 5 秒 TTL / 2 秒 grace，正常默认值不变。应用 ACK、重启持久化和五 Viewer 共享 upstream 已纳入 T0.5 自动集成验收；真实容量压测仍属后续工作。
