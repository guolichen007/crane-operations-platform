# 实时会话协议

POST /api/v1/devices/{id}/live-sessions 申请，POST /live-sessions/{sessionId}/renew 续租，DELETE 关闭。默认 TTL 300 秒，grace 45 秒，采样固定 1 Hz，不接受客户端任意高频采样请求。
Cloud Manager 保存每用户租约并聚合单设备 upstream；首位 WATCH_START，其余 WATCH_RENEW，最后引用释放或过期后 grace 再 STOP。Edge 还会独立按 TTL 退出，Cloud 故障不会永久 LIVE。
WebSocket /api/v1/devices/{id}/stream 使用同源 HttpOnly 开发会话，读取同一缓存；每连接写入有超时，不累积无限帧队列。
Phase 0 manager 为内存 POC，live_sessions 表已预留但未持久化。Cloud 重启后不恢复租约，Edge TTL 保证关闭；持久恢复、应用 ACK 对账与 5 浏览器性能实测列入 Phase 1。开发验收可配置 5 秒 TTL / 2 秒 grace，正常默认值不变。
