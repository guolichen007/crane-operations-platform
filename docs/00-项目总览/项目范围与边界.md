# 项目范围与边界

目标是 20 台行车的全国资产管理与按需观测。Phase 0 建立工程基线和匿名模拟链路，不代表现场投产。
本轮包含目录、规范、契约、Cloud/Edge/Simulator/Web、开发 Compose、迁移、CI、测试与文档。保留既有 Three.js 地图和离线 HTML，公开代码使用匿名登记样例，API 模式只读云端 Shadow。
现场独立运行；云端和浏览器都不接 PLC。远程 Web、点云完整传输在 Phase 2；真实控制不在本阶段。开发身份不可用于生产。无 Kubernetes/Kafka/Redis 或原始点云入库。
旧客户版仅在本机 local-private、release 和旧 Git 分支保留，公共分支无旧提交父链。不得上传本地归档。
