# 里程碑与人工 Gate

Phase 0：企业规范、冻结契约、一个 Shadow、20 台连接、CI 和 Draft PR。验收证据见测试报告，未执行的检查不得记 PASS。
Phase 1：完善持久会话、应用层确认、断网恢复、租约恢复、20 用户/5 LIVE/5 同设备查看性能和生产身份适配。
Phase 2：审查 Gateway + FRP 内部拓扑后实现远程 Web；实现 ROS Adapter 和二进制点云、30 分钟 STANDARD 压测。
Phase 3：资产盘点、适配器、systemd 安装、升级回滚、备份恢复、现场兼容与安全验收。每阶段通过人工评审后再继续，不自动 merge main。
