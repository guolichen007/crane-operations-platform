# ADR-0009：关键事件应用级确认

状态：T0.5 采用，待人工整体审查。

MQTT PUBACK 只确认 broker 接收，不能删除关键事件。Edge 对 ALARM/EVENT 使用容量 256 的持久 spool；Cloud 提交 PostgreSQL 后通过 event/ack 返回 STORED，再由 Edge 持久删除。

丢 ACK 时使用原 messageId 重发；数据库唯一键去重后仍再次 ACK。选择 at-least-once transport + idempotent consumer，不使用分布式事务或 exactly-once 承诺。Linux 文件与目录 fsync 加固突然断电恢复，满队列明确告警，不静默覆盖。
