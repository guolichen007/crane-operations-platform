# Phase1-A1.1-R2 角色日常任务与成熟平台使用场景

## Portfolio Manager 的一天

打开 Portfolio → 看本月进场/延期/冲突 → 新项目登记 → 选择项目模板 → 录入 requested handover → 排工程师/团队/现场窗口 → 系统发现资源冲突 → 调整活动 → 批准计划 → 后续从 Punch/Handover 看交付闭环。

## Platform Admin 的一天

进入授权项目 → 新增行车 DRAFT → 配置 Site/Runway → 录制造商/型号/SN/参数 → 安装 PLC/LiDAR/Camera/VFD → 补文档/标定 → 激活 Asset → Operations 可搜索/定位。

## Maintainer 的一天

Attention Center 看维护到期 → 打开 Equipment → 查看最近 Alarm/Condition → 执行 Inspection → 发现问题创建 Work Order → 更换 Brake/钢丝绳 → 记录备件与结果 → 老安装自动进入历史。

## Operator 的一天

Operations 看在线/告警 → 点击行车 → 实时/Twin → Alarm Focus 到 HOIST_VFD → ACK 告警/发起维护请求 → 不能改 Asset Master。

## Viewer 的一天

只读 Dashboard/Asset/History/Twin；无写 CTA；直接调用写 API 仍 403。

## 事故复盘

打开历史 Alarm → Incident Review → Time Conductor → Configuration@T → 当时 PLC/VFD/LiDAR 软件/标定 → X/Y/Z/load trends → GAP → Replay → Timeline → 导出受控审查结果（后续功能）。
