# 开发部署与配置

node tools/task.mjs bootstrap → dev-up → integration-test → dev-down；Makefile 和 scripts/*.ps1 等价。依赖 Node24.19/npm11.17、Go1.27.3、Docker Compose。
Compose 含 PG17、Mosquitto2、Cloud、Gateway、Web、Simulator；pointcloud 为 profile 但功能关闭。开发不安装系统服务，不改变防火墙或现场网络。
配置优先级 defaults < APP_CONFIG JSON < 环境变量 < CLI；DEV_API_TOKEN、DATABASE_URL 只环境注入。health/live 进程，health/ready 检查 DB 和 MQTT；metrics 为内部运维接口，不经 Nginx 对外代理。
Windows 可在 tools/.cache/go 使用便携 Go；代理通过操作者 GOPROXY 环境设置，不在生产代码绑定镜像。Docker 网络不可达时记录失败，不伪造 Compose PASS。
生产需独立 secret/非 root、HTTPS、备份、资源限制、身份与租户隔离，未提供生产 Compose。
