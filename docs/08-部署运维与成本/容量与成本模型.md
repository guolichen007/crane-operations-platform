# 容量与成本假设

规划 20 台 mostly SILENT、无视频、点云按需，初始 4 vCPU/8GB/100–200GB SSD/单区域/Compose。此为需求预算假设，不是采购报价或实测容量承诺。
假定年度基础云预算 6000–8000 元，需按部署时厂商、地域、带宽、备份和税费核价；代码不绑定云厂商。
心跳约 20/900 条每秒，周期 snapshot 20/3600；5 台 LIVE 约 5 条每秒，每台最多 0.1Hz telemetry_samples。Shadow 仍逐条落库，需跟踪 DB 写入和保留期。
STANDARD 点云每秒约 10000×16×2=320000 字节，约 1.15GB/小时/路（未含协议开销）；公网流量单算，不默认长期上传。后续压测记录内存、队列、延迟、CPU 和浏览器 WS buffer，凭证据再扩容。
