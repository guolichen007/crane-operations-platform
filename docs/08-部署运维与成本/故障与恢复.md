# 故障与恢复

MQTT 断开：Edge 指数退避（1–64秒），租约自然过期；本地自治。告警磁盘队列有界，满时明确报错需运维介入，不无限写盘；普通遥测不补传。
DB 不可用：ready 失败，Cloud 持久化重试、暂缓 MQTT ACK；HTTP 返回服务不可用。恢复后 cache 只反映已提交消息。进程重启从 device_shadow 重建缓存。
Cloud 重启：从 PostgreSQL 恢复未过期 Viewer/Desired State，MQTT 连接恢复后重新发新 generation START，等待 WATCH_ACK；不能把发布成功当成 LIVE。Edge 重启保留 bootSeq/fence，但不恢复旧 LIVE 定时器，BIRTH 触发重新对账。
开发 down 保留 volume，禁止随意 down -v。重建空库只用于隔离 CI。生产备份用 pg_dump/定期恢复演练，forward-fix 先备份，验证版本后升级。
开发证书过期统一停环境并重新生成整套，不把 CA 私钥复制到容器。公开仓库旧历史保护和回退见 local-private 归档，仅本地可用。

T0.5 升级前备份旧库；禁止修改 00001。旧平铺协议不兼容运行，若存在旧 POC spool，应保留归档并人工核对未确认关键事件，不能静默清空或用新进程直接重发旧载荷。正常退出尽力发 DEATH；无网络时不能保证优雅上报，最终仍由 Will/恢复后 BIRTH 收敛。bootSeq/spool 损坏拒绝启动，不能删除状态文件冒充恢复。
