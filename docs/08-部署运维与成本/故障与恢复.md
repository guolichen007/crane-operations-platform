# 故障与恢复

MQTT 断开：Edge 指数退避（1–64秒），租约自然过期；本地自治。告警磁盘队列有界，满时明确报错需运维介入，不无限写盘；普通遥测不补传。
DB 不可用：ready 失败，Cloud 持久化重试、暂缓 MQTT ACK；HTTP 返回服务不可用。恢复后 cache 只反映已提交消息。进程重启从 device_shadow 重建缓存。
Cloud 重启：内存租约丢失，Edge TTL 退出；需要用户重新申请 LIVE。持久租约恢复属于 Phase 1，不能承诺无损恢复所有消费会话。
开发 down 保留 volume，禁止随意 down -v。重建空库只用于隔离 CI。生产备份用 pg_dump/定期恢复演练，forward-fix 先备份，验证版本后升级。
开发证书过期统一停环境并重新生成整套，不把 CA 私钥复制到容器。公开仓库旧历史保护和回退见 local-private 归档，仅本地可用。
