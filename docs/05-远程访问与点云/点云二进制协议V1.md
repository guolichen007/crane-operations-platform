# PointCloud Frame V1

小端 28 字节头：Magic PCD1(4)、Version uint16=1、Flags uint16、TimestampMs int64、Sequence uint32、PointCount uint32、StrideBytes uint16=16、Reserved uint16。随后每点 x/y/z/intensity 四个 float32，共 16 字节。
LOW 5000×1 Hz；STANDARD 10000×2 Hz（默认）；ENHANCED 20000×2 Hz；HIGH 30000×2 Hz。拒绝超长、错误 stride/version 和长度不符。浏览器 binaryType=arraybuffer。
contracts/pointcloud 提供边界验证与 Latest 队列，慢消费者旧帧被替换，只保留一帧，有 dropped 计数。核心不依赖 ROS topic；PointCloudSource 接口由资产盘点后适配。
当前只有协议/队列原语与关闭的 bridge 命令，不实现 ROS 采集、网络上传或云端算法。后续 source-topic 通过配置提供。禁止 MQTT、JSON/Base64 和默认 PostgreSQL 保存。
